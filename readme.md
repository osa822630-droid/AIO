# TubeAIO Speed — محمّل الفيديو والصوت بالسرعة المخصصة

تطبيق أندرويد (Java 17) مخصص لتحميل مقاطع الفيديو والصوت وقوائم التشغيل الكاملة مع **دمج السرعة المطلوبة مباشرة داخل الملف (`0.25x` – `4.0x`)** بحيث يعمل الملف بالسرعة المختارة جاهزاً على أي مشغل دون الحاجة لضبط السرعة يدوياً في كل مرة.

## المزايا الفعلية في الكود
1. **تحميل بالسرعة المدمجة (Baked-in Speed Downloading)**:
   - سرعات من `0.25x` إلى `4.0x` (افتراضياً `1.5x`) مع الحفاظ الكامل على نبرة الصوت الطبيعية عبر سلسلة فلاتر `atempo` (WSOLA) في FFmpeg.
   - **وضع الفيديو التوربو (`-itsscale` + `-c:v copy`)**: تعديل طوابع الوقت للفيديو دون إعادة تكويد إطارات الفيديو، مع تراجع تلقائي (`fallback`) إلى `libx264 ultrafast` عند الحاجة.
   - **توحيد ورفع وضوح الصوت (`dynaudnorm`)** بدون تغيير النبرة.
2. **دعم قوائم التشغيل الكاملة (Playlists)**:
   - استخراج عناصر قوائم التشغيل عبر `NewPipeExtractor` و`yt-dlp --flat-playlist`، مع تحديد المقاطع وإنشاء مجلد فرعي باسم القائمة وترقيم تلقائي (`01 - Title_1.5x.mp4`).
3. **مزامنة ملفات الترجمة مع السرعة (`SubtitleSpeedScaler`)**:
   - تنزيل ملفات الترجمة (`.srt` / `.vtt`) وإعادة حساب توقيتها بالقسمة على معامل السرعة (`time / speed`) لتعمل متزامنة تماماً مع الفيديو المسرّع.
4. **معاينة السرعة بالبث المباشر (`Live Speed Preview`)**:
   - تجربة تشغيل الرابط بالسرعة المختارة عبر مشغل `ExoPlayer` المدمج قبل بدء التحميل الفعلي.
5. **تسريع الملفات المحلية (`LocalSpeedFragment`)**:
   - اختيار أي ملف فيديو أو صوت موجود على الهاتف وتحويله إلى نسخة مسرّعة بدون إنترنت.
6. **خدمة خلفية دائمة (`SpeedDownloadForegroundService`) وإعدادات شاملة (`SettingsActivity`)**:
   - اختيار مجلد الحفظ، تحديد الحد الأقصى للتحميلات المتزامنة (`1` إلى `4`)، وضع الواي فاي فقط، تحديث محرك `yt-dlp` من داخل التطبيق، وثيم نهاري/ليلي (`Material3.DayNight`) مع تبديل فوري بين العربية والإنجليزية (`457` نصاً متطابقاً).

## المواصفات التقنية
- **اللغة والبناء:** 100% Java (`Java 17`), Android Gradle Plugin `9.0.1`, ViewBinding.
- **النظام المدعوم:** `minSdk 30` (Android 11+) — `compileSdk 36` / `targetSdk 36`.
- **المحركات المدمجة:** `youtubedl-android 0.18.1` (`yt-dlp` + `FFmpeg` + `aria2c`), `NewPipeExtractor v0.26.2`, `ExoPlayer 2.19.1`, `ObjectBox 5.4.2`.
